VAULTOS LOCAL BROWSER

Only localhost pages can be loaded

This browser operates inside VaultOs's air-gapped security profile. Only local loopback addresses on this device (127.0.0.1, localhost, [::1]) can be opened here — external internet pages are intentionally blocked.

http://127.0.0.1:8080/
Open Offline Wiki (Kiwix) Retry Localhost (:8080)

How Offline Browsing Works Here

  • External URLs and internet search queries are stopped on-device before any lookup leaves the phone.
  • By default, the startpage points to http://127.0.0.1:8080/ for a local Kiwix or documentation server.
  • When Wi-Fi/Hotspot are off in air-gapped mode, Kiwix does not run an HTTP listener automatically — tap Open Offline Wiki (Kiwix) above to read all offline ZIM archives directly in the Kiwix app.
